## 📂 Repository Structure & Modules

### 🔐 Authentication & Security
* **`05-auth-backend` / `06-auth-middleware`**: Core backend authentication, JWT implementation, and custom Express middleware logic.
* **`cookie-auth` / `cookie-auth-frontend`**: Implementing HTTP-only cookie-based authentication between Express backend and React frontend.
* **`next-auth`**: Exploring NextAuth.js for robust session management and OAuth integrations in Next.js apps.
* **`signup-page`**: Full-stack user registration flow with validations.

### 🏗️ Backend Architecture & Best Practices
* **`07-MVC`**: Structuring Node.js/Express applications using the Model-View-Controller architecture.
* **`08-errors`**: Implementing global error handling and centralized response formatters.
* **`09-pagination`**: Database query optimizations using pagination techniques.
* **`middleware-test` / `CRS-test`**: Deep dive into Express middlewares and handling CORS policies.
* **`openapi-demo`**: Documenting REST APIs using OpenAPI/Swagger specifications.

### ⚡ Next.js & Rendering Strategies
* **`ssr-test`**: Implementing Server-Side Rendering (SSR) for dynamic data fetching.
* **`ssg-test`**: Working with Static Site Generation (SSG) for performance-optimized builds.

### 🛠️ Advanced Tooling, DevOps & Monorepos
* **`monorepo` / `my-turborepo`**: Structuring large scalable applications using Turborepo (managing multiple apps and shared UI/config packages in one repo).
* **`CI-CD`**: Setting up continuous integration and continuous deployment pipelines (GitHub Actions).

### 🚀 Full-Stack Major Projects & Live Classes
* **`Paytm_project` / `Paytm-project` / `paytm-project-starter-monorepo`**: End-to-end full-stack digital wallet application inspired by Paytm, handling database transactions and monorepo structure.
* **`project-01`, `project-02`, `project-03`**: Various cohort practice assignments and API building modules.
* **`week-15-live-1`**: Live cohort implementations and advanced concept coding.
